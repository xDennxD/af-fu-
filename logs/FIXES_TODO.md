# Offene Fixes aus Log-Analyse

Wird vom Log-Watcher gepflegt. Für eine lokale Claude-Code-Sitzung:
offene Punkte (`- [ ]`) abarbeiten, danach abhaken und den Eintrag mit Commit-Hash ergänzen.

Format pro Eintrag:

```
## [YYYY-MM-DD] <Logdatei> – <Kurzbeschreibung>
- [ ] Status: offen
- Projekt/Datei: <pfad:zeile>
- Fehler: <Fehlermeldung>
- Ursache: <Analyse>
- Lösungsvorschlag: <konkrete Schritte>
```
